# 学生单科深读

给学生本人出一份单独的 A4 报告。比全科报告多写试题讲解和按知识点归纳的情况。用这场试卷的具体设问、数据、图表或实验条件解释解题思路，减少通用话术。

## 先对齐这场考试的材料

1. 按姓名、班级和学号找到学生，核对学科总分、分制、小题分和试卷版本。用该科全卷和官方答案或评分细则建立原题映射。本场已核对的该科映射直接复用。其他科目不需要读卷。
2. 把所有低于满分的有效评分项按原题顺序列出，部分得分也要列。为每项保留题号或小问号、实际得分、满分、失分、具体知识点和可追溯的试卷页或评分条目。完整同口径资料要核对题目失分合计。合并计分的列标注范围，说明范围内分别考了什么，一起讲解，分数只列合计。对分值缺失的项标出「缺评分记录」，可以说明该题考点。
3. 小题分能定位哪道题失分。用原卷和评分依据讲清该题应怎样做、有哪个得分点值得核对。有答卷或批注时进一步指出实际失分步骤，并用答卷佐证。缺答卷时用「重做时检查……」「对照细则看是否写出……」，避免把推测写成学生做错的原因。缺官方答案时，用能从原题核实的解法讲解，评分点留待确认。

## 报告结构

- **本场化学（或对应科目）成绩**。写总分、满分、各题型得分、排位和前百分比（能核对时）。用题目或得分点说明本场已经做得好的地方。赋分和卷面分分开写。
- **知识点分析**。用学生能懂的话说明哪些知识点这次失分集中，列出关联题号和证据。分清同一知识点在基础题和综合题中的表现。对同一评分项可列主考点和相关考点，汇总扣分时只算一次。合并计分的题标注分数属于整组。结论限这张卷、这些题和答卷能支持的范围。可顺手指出一处同类题中已有的得分，帮助学生知道哪些步骤能保留。
- **逐题讲解**。每个失分项都有可定位的小标题，紧跟得分、满分、扣分和具体考点。讲清原题在问什么、从哪条信息或条件入手、关键步骤怎么写，以及怎么用原卷或评分细则自查。选择题可以点出关键选项为何成立或不成立，有选项记录时针对学生所选讲。解答题以题目给出的实际条件说明推理或计算，把能核实的要点对到小问；已有得分可以肯定，具体漏写哪一步按答卷确认。题目很短时用一段讲清，综合题按关键步骤展开。可合并讲相近题，但每个题号的分数、考点和订正动作应可查。
- **本场订正**。末页按失分集中度、基础性和同类题迁移价值排顺序，给「重做哪些题、做完怎样确认会了」。例如重做一道平衡题后，换一个条件再判断移动方向，并说明依据。题目数量按该生情况安排。

写法示例（虚构）。「第12题｜1／3 分，失 2 分｜化学平衡移动。原题给出反应的热效应，问升温后平衡向哪边移动。先在反应式旁标出吸热方向，再按题设温度变化判断平衡移动。订正时把『移动方向』和『热效应依据』各写一句，对照原题检查这两处有没有写全。」

## 统计与导出

按 [数据和计算](data.md) 规范成绩表。只需准备该科的定义和小题分，同卷实考数据可用于对照。下面用虚构学号示例。

```sh
python scripts/metrics.py input.json stats.json --student-id 001 --subject 化学
python scripts/render.py body.html report.pdf --kind student --subject 化学 --student-name 学生甲 --class-name 示例1班 --exam 五月第一次模拟考试
```

统计结果中的 `losses` 是逐题讲解清单，`missing_items` 是缺评分记录，`groups` 提供该生按试卷分段的已记分和已覆盖满分。若组内有空白，标明覆盖范围。班级或年级项目仍按同一科的有效记录统计。只交付该生该科的 PDF，沿用学生个人报告的封面和内页样式，封面标出科目。逐题讲解可使用 `section.advice`，长题按小问拆段。交付前交叉核对每条有效失分都出现在逐题讲解、合并计分未被拆分或重复，报告中题目条件与评分依据匹配，PDF 中文和长页显示正常。
