# 数据和计算

## 读表与题号

用当前环境的表格工具读取 Excel 的缓存值与表头。筛除汇总行。文本型学号和考号按原样保留前导零，统一同一学生的键。核对班级别名、试卷版本、主表和小题分的总分差异、不同分制（原始分、赋分）及客观题和主观题分值。发现差异时按原表字段分别保留并注明，只有已确认同一分制时才做加和核对。数字零有两个可能来源，要结合状态、有效排名和考试记录确认它是否是实得零分。按实考确认后再送入统计脚本。

逐题映射示例「12–14｜填空题｜15分｜第12题导数的几何意义和切线，第13题椭圆与抛物线，第14题平面向量」。只有合计列时，所失分数归在合计列。看得到小问评分，才逐小问归因；仅有得分时，描述“这道题考什么、丢了多少分、可以怎么查”，可以提示看答卷确认扣分步骤。OCR 只用于找内容，题号、公式、图示、满分有疑点时回看原页。

## 统计口径

- 单科均分以该科有效成绩为分母。题目得分率按该列所有有效得分的合计除以相应满分合计。空白项省略，零分计入，同时记录各题有效人数与零分人数。题型得分率用对应评分列的有效得分合计 ÷ 对应有效满分合计。班级和年级差值用百分点。
- 排名优先采用可信的原表，核对分制、范围与同口径参评人数。只有确认完整可比的参评范围时才重算，重算使用并列同名次的竞赛排名。展示如「年级第 87 名／共 420 人」「前 20.7%」。前百分比＝名次÷同口径参评人数。组合总排名标明「年级同选科组合」，按同一原表口径找人数。名次或人数无法核对时省略对应值。
- 可用题目难度、班级与年级差值、零分和部分得分人数、题目分值以及可否迁移到同类题，判断哪些值得在报告展开。全班本题相对弱和学生这题失分是不同的证据。只对有效人数足够、试卷版本一致的样本做具体比较。
- 异常行、缺失列、没有有效成绩的科目先列在工作记录。试卷齐全时照常建立全科考点。有成绩无小题分时，先提供能核实的成绩信息，并在报告相关位置说明逐题资料缺失。适用科目有语文、数学、英语、物理、历史、化学、生物、地理、思想政治，满分和人数由本场确定。

## 统计脚本

用表格工具规范成 UTF-8 JSON，再执行 `python scripts/metrics.py input.json stats.json`。两条命令路径均可使用绝对路径。脚本用 Python 3.8 或以上版本的标准库，输出班级与年级单科统计、题型和逐题统计，以及指定班级学生的逐题失分。排名、组合范围和文案由当前任务核对并补充。

以下为虚构示例。每科 `items` 为空时仍可汇总该科总分。题目未映射的知识点写「待核实」，题目满分未知时先不纳入统计。

```json
{
  "target_class": "示例1班",
  "students": [
    {"id":"001","name":"学生甲","class":"示例1班","scores":{"数学":6}},
    {"id":"002","name":"学生乙","class":"示例2班","scores":{"数学":5}}
  ],
  "subjects": {
    "数学": {
      "max":10,
      "items":[
        {"id":"k1","question":"1","max":4,"group":"选择题","topic":"集合的交集"},
        {"id":"z2-3","question":"2–3","max":6,"group":"填空题","topic":"第2题指数大小比较、第3题二次函数的零点"}
      ],
      "rows":{
        "001":{"k1":0,"z2-3":6},
        "002":{"k1":4,"z2-3":1}
      }
    }
  }
}
```

每个学生的 subject score 留空（null）表示没有有效成绩，rows 中以题目 ID 为列，缺题留空（null）或省略。仅将已确认有效成绩的学生送入对应小题分的 rows。组别使用试卷的自然分段，也可以为「客观题」「主观题」。
