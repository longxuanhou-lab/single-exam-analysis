# 报告写法和版式

## 教师用学科报告

一科一份 PDF。封面用对应科目的手绘小书人，标题「学科成绩分析」，填写班级和本次考试名称。米白纸色、深绿线条和大字，底部保留装饰线即可。内页用白底、深蓝页眉、青绿色重点。按需要分页，避免内容挤成小字。

- 概览说清本班和年级有效人数、单科均分及差值。结合试卷分段、题型得分率和实际题目，交代本班做得较稳、相对薄弱、失分较集中的地方。
- 下一页标题用「{科目} · 讲评建议」。每组按相关题目自然组织，题号旁列本班／年级得分率，必要时引用零分人数、部分得分人数、分数或评分步骤。条数由本班答题情况决定。用备课建议的口气，说明先看什么材料、适合讲哪个知识点、哪类题可以一起看。合计计分的题可建议分别重做以定位失分。按实际证据写，答卷缺失时用「可以核对」「值得看一下」表达需要核查的内容。
- 逐题明细附后，保留题号、考点、满分、本班／年级得分率、差值，必要时加有效人数。长表格重复表头，组内保留原评分口径。

例「第5题可以先把三角形的边和对角配起来，再说什么情况下用正弦定理，什么时候用余弦定理。」如果同一科只一处值得展开，可以详写这一处。数据较丰富时，可以把相近题型合写，或把部分得分较多的一道大题单独说清楚。

如明确要求班级或年级汇总，可用同一内页样式，对应调整统计范围，写总览、各科表现和需要优先复盘的地方。保持样本和比较口径可核对。

## 学生个人报告

封面用坐着读书的小书人，填姓名、班级和考试。内页用清爽白底、墨绿标题，失分重点可用浅橙色。正文直接写给学生。

- 「本场总览」给总分、可信的排名和前百分比、各科成绩与年级参照。用题目、某部分得分或相对位置说清做得好的地方，以及从哪里开始看。
- 各科解释本场得分、各部分表现和可定位的所有非满分评分项。表格列「题号｜得分／满分｜失分｜这道题考什么」。长清单可续页，合计计分要说明。发现缺小题分时在相应科说明。用一两句贴合实际的观察指出主要问题，描述得分能说明的事实。
- 「本场订正」放最后，按实际需要安排练习顺序。每项写题号、知识点、建议的做法和自查方法。例如「第16题空间向量。先重画正方体，写出用于证明垂直的向量，再对照评分细则检查二面角用的是哪两个法向量。」订正量及详略由学生的具体失分决定。不给家长陪读话术。

## 生成 PDF

`scripts/render.py` 使用 `templates/report.css` 排版。封面图按 `SKILL.md` 的 PDF 模板文件清单读取。写一个 UTF-8 HTML 片段作为正文，脚本使用 Python 3.8 或以上版本，浏览器使用系统的中文字体。路径以实际文件为准，命令支持绝对路径。

```sh
python scripts/render.py body.html report.pdf --kind subject --subject 数学 --class-name 冲刺1班 --exam 五月第一次模拟考试
python scripts/render.py body.html report.pdf --kind student --student-name 学生甲 --class-name 冲刺1班 --exam 五月第一次模拟考试
```

汇总报告用 `--kind overview --title 标题`。可加 `--brand 高考冲刺 --series 半年班` 在封面顶部显示项目，或省略。脚本以本机 Edge、Chrome 或 Chromium 打印。可用 `--browser` 指定路径，或用 `.html` 输出自带插画和样式的完整网页，再通过当前环境的 PDF 工具导出 A4，启用背景图形，关闭浏览器自带页眉页脚，边距设为无。

正文片段按以下结构写。讲评建议独立起页，逐题明细在下一节。每个 `article.sheet` 自动另起一页。段落、建议组和表格行尽量保持完整，表头随表重复。逐题长表优先在自然分组处安排续页，续页记得带题号和同一套表头。

```html
<article class="sheet">
  <header class="pagehead"><small>考试名称</small><h1>数学 · 1班学科分析</h1><p>本班有效成绩人数 · 年级有效成绩人数</p></header>
  <main>
    <div class="cards"><div><small>本班均分</small><strong>75.8 分</strong><small>满分 150 分</small></div></div>
    <h2>各部分得分</h2>
    <table><thead><tr><th>试卷部分</th><th>本班</th><th>年级</th></tr></thead><tbody><tr><td>选择题</td><td>…</td><td>…</td></tr></tbody></table>
    <aside>结合这次得分补一条有具体题号的观察。</aside>
  </main>
</article>
<article class="sheet">
  <header class="pagehead"><small>考试名称</small><h1>数学 · 讲评建议</h1><p>根据本班这次答题情况整理</p></header>
  <main>
    <p class="table-note">各题得分率依次为本班、年级</p>
    <section class="advice"><h3>先看第5题的边角关系</h3><p class="evidence">第5题 64.0% ／ 70.6%</p><p>可以先把边和对角配起来，再比较两个定理的使用条件。</p></section>
  </main>
</article>
```

正文使用与本次材料相符的数字。学生版复用 `sheet`、`pagehead`、`cards`、`aside` 和 `table`，用 `<tr class="focus">` 标出末页安排的重点题。上述数字用于说明写法，实际产物从当次数据生成。交付前渲染并检查封面、建议页、最密的表格和分页边界。
